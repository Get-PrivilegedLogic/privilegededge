# PrivilegedEdge

Secure Kubernetes edge platform built on Raspberry Pi 5 using K3s, AWS integrations, observability, RBAC, and GitOps workflows.

## Project Progress

## Current Architecture

- Raspberry Pi 5
- Ubuntu Server 24.04 LTS
- K3s Kubernetes
- Traefik ingress controller
- NGINX test workload

### Completed
- Installed K3s on Raspberry Pi 5
- Verified cluster health and core system pods
- Deployed NGINX workload
- Exposed application using a NodePort service
- Created first declarative Kubernetes Deployment manifest
- Applied Deployment using `kubectl apply`

### Key Concepts Learned
- Imperative vs declarative Kubernetes workflows
- Kubernetes Deployments
- Replica management
- Labels and selectors
- Desired state management
- Basic `kubectl` operations
